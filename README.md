# Autostrada del Sole — spatial-staggered DiD

R code for the empirical part of Lelo & Tani (2026).
The design crosses Callaway-Sant'Anna staggered DiD with
Ciani-de Blasio distance rings.

## Run

```r
setwd("/path/to/Share")
source("R/main.R")
```

## Outputs

* `output/tables/*.csv,*.tex`
* `output/figures/*.png,*.pdf`

## Files

```
R/
  00_setup.R              packages + helpers
  01_prepare.R            panel + treatment + cohorts + rings + samples
  02_descriptive.R        cluster analysis + intercensal growth
  03_csdid.R              Callaway-Sant'Anna staggered DiD
  04_spatial_rings.R      Ciani-de Blasio rings with explicit spillover
  05_spatial_staggered.R  spatial × staggered (combined novelty)
  06_aree_interne.R       focus on ISTAT inner-areas classification
  main.R                  master pipeline
data/

  cluster_1961.rds        generated by 02_descriptive.R
archivio/

```
